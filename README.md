# MTUCI Task Manager

Telegram-бот и Mini App для личных и групповых задач. Пользователь может создавать задачи, менять их статус и удалять их; в Mini App также доступны группы, участники, назначение ответственного и Telegram-уведомления.

## Запуск

Требуется Go 1.23 или новее.

1. Создайте `.env`:

   ```dotenv
   TELEGRAM_BOT_TOKEN=123456:token
   WEBAPP_URL=https://example.com
   SERVER_PORT=8080
   ```

2. Запустите приложение:

   ```bash
   go run .
   ```

`WEBAPP_URL` должен быть абсолютным HTTPS URL — это требование Telegram Bot API. Для локальной проверки API без Telegram можно временно задать `DEV_MODE=true`; этот режим нельзя включать в production.

## Проверки

```bash
go test ./...
go test -race ./...
go vet ./...
```

## Важные особенности

- Mini App отправляет `Telegram.WebApp.initData` в заголовке `Authorization: tma ...`; сервер проверяет HMAC-подпись и срок действия данных.
- Добавлять и исключать других участников может только создатель группы. Обычный участник может самостоятельно выйти.
- Добавить по `@username` можно пользователя, который хотя бы раз открыл бота или Mini App после запуска сервера.
- Сейчас данные находятся в памяти процесса и очищаются при перезапуске. Для production следует подключить постоянное хранилище.
